## My personal site where I share writings and other things I find interesting

currently I use [hugo](https://gohugo.io/) for this and I'm someone who likes to make stuff easy for himself so
I'm using obsidian to do my writings etc and typst for version controlling my cv

---

### tools

- [hugo](https://gohugo.io) — static site generator, fast, no runtime, deploys as plain HTML
- [tailwind](https://tailwindcss.com) — styling
- [obsidian](https://obsidian.md) — where I actually write. I combined it with hugo so the whole repo is the obsidian vault. I use templates to pre-fill frontmatter for articles and yt-picks so writing a new post is just filling in the content and committing.
- [typst](https://typst.app) — cv lives in `/cv` and compiles to a pdf. plain text, version controlled, using the [basic-resume](https://typst.app/universe/package/basic-resume) template so I only touch the content.
