## my take

I've used LLMs since 2022. Like Matt, I've never fully trusted them. At work I build critical services that handle tens of thousands of requests a day, so I verify everything: read the docs, test it, check twice. But for personal projects, I catch myself reading an answer, thinking "sounds right," and closing the tab.

## learnings

- LLMs are incentivized to guess, confidently, even when they don't know
- Think of LLM training like image compression: the more you compress, the more detail is lost. Don't ask it to reconstruct what's missing, give it the full picture
- Use the search tools LLMs offer instead of relying on their training
- Prompt injection is real, malicious content in context can hijack what the LLM does next
